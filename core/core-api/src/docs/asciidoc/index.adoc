== 개요

성공 응답은 리소스 표현을 그대로 내려준다.
오류 응답은 RFC 9457 Problem Details(`application/problem+json`) 형식이며 `code` 확장 속성으로 에러 코드를 전달한다.

== 오류 응답

=== 에러 코드

[cols="1,1,3"]
|===
| code | HTTP status | 설명

| C001 | 400 | 요청이 올바르지 않음 (검증 실패, VO 생성 실패)
| C002 | 404 | 리소스 없음
| C003 | 405 | 허용되지 않은 메서드
| C004 | 415 | 지원하지 않는 미디어 타입
| C999 | 500 | 서버 내부 오류
| M001 | 404 | 회원 없음
| M002 | 409 | 이미 탈퇴한 회원
| M003 | 409 | 활성 상태가 아닌 회원
| O001 | 404 | 주문 없음
| O002 | 409 | 결제할 수 없는 주문 상태
| O003 | 409 | 취소할 수 없는 주문 상태
| O004 | 409 | 결제 대기 주문 한도 초과
| P001 | 404 | 결제 없음
| P002 | 409 | 승인 대기 상태가 아닌 결제
| P003 | 502 | PG 가 승인하지 않음 (결제는 FAILED 로 남음)
|===
