유효한 CA 가 없습니다. Root CA 발급
주체 DN 과 SAN 은 CSR 의 것을 씁니다. 예: openssl req -new -key device.key -subj "/CN=api.example.com" -addext "subjectAltName=DNS:api.example.com"
SAN 은 프로파일 템플릿을 씁니다. 예: openssl pkey -in device.key -pubout
